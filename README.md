Most of my projects start with *"how does this actually work?"* and end with me
having learned three things I never set out to learn. I used to work as a web
developer for about seven months — good experience, but I kept getting pulled
back down to the metal. These days I mostly live in the layer between hardware
and software: CPUs, operating systems, digital logic, and all the weird little
details that make the two actually talk to each other.
